## Release notes for 1.59.0
=======

### New Features/Updates:

- Added Node.js 24 support for SDK development, build, and release pipelines.
- Replaced native Node Sass usage with Dart Sass compatibility for current Node.js runtimes.
- Added native Entra External ID support for local mock-user sign-in.
- Added first-release publishing support to the SDK release pipeline.
- Added SBOM package metadata and CodeQL scanning to improve build security and compliance.

### Bug Fixes:

- Fixed local builds that failed with `ERR_OSSL_EVP_UNSUPPORTED` on newer Node.js versions.
- Fixed package restore failures caused by registry and authentication mismatches.
- Updated vulnerable transitive dependencies, including Axios, node-forge, and minimatch.
- Increased container health-check retries to reduce package-build timeout failures.
